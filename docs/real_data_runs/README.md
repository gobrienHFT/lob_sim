# Real Data Runs

This directory contains committed report-only artifacts from local public-data tape runs. Raw market-data files, event traces, local packs, and secrets are intentionally not committed.

- [raw_1780500354_10m.md](raw_1780500354_10m.md): BTCUSDT target-window public-data report, generated from a 609.96s local tape with raw data kept out of git.
- [raw_1780500354_10m.json](raw_1780500354_10m.json): machine-readable summary for the target-window run.
- [raw_1772633471.md](raw_1772633471.md): earlier BTCUSDT local public-data report, clearly labeled as a short available tape below the 10-30 minute target.
- [raw_1772633471.json](raw_1772633471.json): machine-readable summary for the same short run.

For the reproduction path, use [../real_data_runbook.md](../real_data_runbook.md). For a blank publication checklist, use [../real_data_results_template.md](../real_data_results_template.md).

# Real Data Runs

This directory contains committed report-only artifacts from local public-data tape runs. Raw market-data files, event traces, local packs, and secrets are intentionally not committed.

- [raw_1772633471.md](raw_1772633471.md): BTCUSDT local public-data report, clearly labeled as a short available tape below the 10-30 minute target.
- [raw_1772633471.json](raw_1772633471.json): machine-readable summary for the same run.

For the reproduction path, use [../real_data_runbook.md](../real_data_runbook.md). For a blank publication checklist, use [../real_data_results_template.md](../real_data_results_template.md).

# Real Data Results Template

Use this template for a larger public-data tape run generated by `scripts/run_real_data_report.py --publish-dir docs/real_data_runs`. New committed publications should be report-only: one Markdown file and one JSON file using schema `lob_sim.real_data_report.v3`, with evidence gate schema `lob_sim.real_data_evidence.v1`. Existing v1 reports are historical pre-streaming artifacts and remain unchanged.

## Limits

- Public L2 cannot prove private queue identity, hidden liquidity, or exchange execution reports.
- Depth reductions may include cancels and trades.
- Negative or positive PnL is not the point; results are replay/audit/fill-source/queue evidence.
- Results are replay infrastructure evidence, not alpha, profitability, production latency, or gateway-readiness claims.
